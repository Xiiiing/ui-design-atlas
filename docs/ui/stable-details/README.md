# 详情开关稳定性

问题：点击右侧“详情”，原布局增加一列，预览宽度改变；自动模式的 iframe 随之重新排版，居中组件明显横跳。页面和案例还存在另一条黄金比例列宽覆盖，实际缩窄范围取决于资源类型。

修复：说明面板绝对定位在预览右侧，独立滚动，不参与画布布局。桌面面板从工具栏下方开始，设备、主题和全屏按钮保持可用；工具栏高度按实际测量，兼容换行。窄屏沿用完整覆盖及预览 inert 行为。说明临时覆盖画布右侧内容，关闭或进入全屏可查看完整演示。详情开关不再调度预览缩放，保留打开时定位关闭按钮、关闭后恢复开关焦点的行为。
