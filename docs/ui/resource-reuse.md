# 资源源码交付与搜索排序验收

对应 Issue #8。源码页默认加载当前资源文件，完整项目源码按需展开；原完整项目 ZIP 与原创 HTML 导出保留。

## 行为与边界

- 构建为 39 个开源资源生成独立 JSON 和资源文件 ZIP，包括入口、显式支持文件、递归本地 import/export/dynamic import、CSS import、当前演示使用的静态 SVG 头像、来源许可证和接入说明。缺失本地引用、未声明外部依赖或缺失锁定版本时构建失败。
- 默认源码请求为 `code/resources/<type>-<id>.json`；仅点击“查看完整项目源码”时请求原整项目 JSON。复制当前文件、下载单文件、下载资源文件包、下载完整项目分别保留独立入口。
- 安装命令来自各项目锁文件的直接依赖版本；配置和 package.json 保留完整项目原文供参考。资源文件包用于接入已有 React/TypeScript 应用，不承诺独立运行。后台组件的 Router、QueryClient、业务 Provider 与调用参数需要沿用完整项目上下文或适配；完整项目 ZIP 是直接运行原演示的入口。
- 原创组件继续导出可直接打开的 HTML；原创页面/案例保留其源码上下文。
- 搜索预建双语索引，规范化大小写、空白和全角字符。优先精确名称、名称包含、多词名称匹配、别名/标签/库信息、描述及其他元数据；所有查询词必须命中，同分保留输入顺序。无查询时保留原目录顺序。
- 列表与快捷搜索共用排名。列表仍按资源类型分组，搜索时最佳匹配所在分组排在前面，组内保持相关性顺序；筛选在排名前应用。

## 验收证据

- `npm run check`：内容与来源检查、外层和两套演示类型检查、5 项 Node 单元测试。
- `npm run build`：两个独立演示、完整项目 ZIP、39 份资源清单与 ZIP；原有大型演示 chunk 体积提示仍存在。
- `npm test`：48 项 Playwright，包含资源默认请求不加载整项目、文件选择、剪贴板、下载、整项目展开/返回、语言切换、503 重试、迟到响应隔离，以及双语搜索、别名、多词、筛选、历史恢复与既有回归。
- 对 39 个资源 ZIP 进行 CRC 检查，并逐文件核对内容与对应 JSON 完全一致；来源许可证包含无扩展名的 Ant Design / Fluent UI 文件。
- 将流光边框和 Ant Design 表格 ZIP 解压到两个临时 React 宿主，增加 HTML 与渲染入口，使用所附 Vite 配置构建；浏览器验证登录输入与表格排序，无页面错误。复用了本地已经按锁文件安装的依赖，未重新联网安装。没有把后台路由组件宣称为独立可运行组件。
- `node scripts/capture-resource-reuse.mjs`：在本地子路径服务运行后，采集 1440/768/375px × 中英文 × 明暗模式共 12 张展开接入说明的源码页截图；无文档横向溢出和页面脚本错误。[机器记录](resource-reuse/verification.json)。
