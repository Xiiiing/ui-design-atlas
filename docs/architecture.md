# 图鉴应用结构

`app.js` 负责创建控制器、持有共享状态、分发页面事件和触发顶层渲染。各控制器通过显式参数接收依赖，读取同一个 `appState`；它们在首次渲染前创建一次，不在页面切换时重建。

| 模块                      | 职责                                                                 |
| ------------------------- | -------------------------------------------------------------------- |
| `atlas/navigation.js`     | 解析路由，保存栏目浏览位置，恢复历史和主导航焦点，更新导航收缩状态。 |
| `atlas/resource-views.js` | 渲染导航、资源卡片、标签、来源、关联资源和说明页面。                 |
| `atlas/browse.js`         | 渲染列表与筛选控件，计算当前结果，更新筛选 URL 和条件标签。          |
| `atlas/viewer.js`         | 管理详情、演示画布、设备尺寸、主题同步和案例页面切换。               |
| `atlas/source-code.js`    | 加载资源或项目源码，缓存请求，并防止过时响应覆盖当前资源。           |
| `atlas/search.js`         | 渲染快捷搜索结果，处理搜索弹层内的键盘操作。                         |
| `atlas/clipboard.js`      | 复制、手动复制回退、下载与提示反馈。                                 |

共享状态通过对象引用传递，避免在创建控制器时缓存路由、语言或当前资源的旧值。栏目记忆和滚动保存计时器归导航控制器所有；源码请求缓存和请求序号归源码控制器所有；提示反馈计时器归剪贴板控制器所有。iframe 消息校验与浏览器事件注册保留在入口，事件顺序不因文件拆分而改变。

`catalog.js` 保持静态目录、查找索引与全局计数的职责，`live-cards.js` 管理卡片 iframe 的可见性和加载预算，`shell/` 保留控件和外观实现。结果分组数量仍基于当前筛选结果，不能用全局计数替代。

## 样式维护

`market.css` 保留有效规则的原始顺序。清理重复声明时，核对选择器、外层媒体条件、属性及 `!important`；保留浏览器兼容性回退，不能根据一次页面扫描删除动态状态选择器。更改样式后验证列表、筛选展开、体验、详情和代码面板，以及不同尺寸、语言和主题。

## 构建与验证

`scripts/build.mjs` 打包入口，并将 `atlas/` 源文件随静态产物复制。`scripts/check.mjs` 自动检查该目录中的 JavaScript 文件，不必为每个新模块单独维护文件清单。

```sh
npm run verify
```

页面变化还需实际检查导航、焦点、历史恢复、主题、键盘和触屏流程；构建通过不能替代交互验证。

## 开发与可重复验证

首次运行需要 Node.js 24.12 或更新版本：

```sh
npm ci
npm run setup:examples
npx playwright install chromium
npm run dev
```

开发入口为 `http://127.0.0.1:4173/ui-design-atlas/`，可用 `PORT=4180 npm run dev` 改端口。一个进程管理主站和两个示例的 Vite 服务；示例使用自动分配的内部端口，经主站 HTTP/WebSocket 代理访问，保持 iframe 同源。端口占用时启动失败，不复用已有服务。退出时关闭所有服务和源码生成任务。

主站 CSS 热更新；命令式入口、HTML 和目录数据变化自动刷新页面，避免重复注册事件。两个 React 示例使用 Fast Refresh，不能局部更新的边界会刷新。开发时直接修改源码即可，不需要重建生产目录。目录生成文件仍遵循原有内容生成流程。

源码清单、许可说明和 ZIP 由开发服务按需生成，使用与生产构建相同的 `delivery` 模块。修改后失效并合并生成请求；每代产物只在完整生成后可见，过期且不再读取的产物会回收。源码面板同步清除请求缓存，原创演示的源码通过明确的原始文件请求读取，不包含 Vite 转换代码。

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 热更新开发环境，不依赖现有 `dist`。 |
| `npm run check` | 内容、出处、严格类型检查和单元测试。 |
| `npm test` | 先构建，再运行全部生产 Playwright 测试。支持 `npm test -- tests/search.spec.mjs`。 |
| `npm run test:built` | 明确复用已完成的构建，适合刚执行过构建的 CI 或本地流程。 |
| `npm run test:dev` | 在临时副本中修改源码，验证热更新、交付文件、错误恢复和服务退出。 |
| `npm run verify` | 检查 → 构建 → 全部生产测试 → 开发环境测试；CI 使用同一入口。 |
| `npm run preview` | 查看生产构建，不监听源码变化。 |

生产验收固定使用 4173 端口，禁止复用未知服务。运行验收前关闭占用该端口的开发服务，或者将开发服务设为其他端口。

`app.js` 和 `atlas/` 的 JavaScript 模块通过 `@ts-check` 与共享类型进行严格检查。DOM 查询区分必需元素和可选元素；事件处理先检查目标类型，共享状态明确表示没有选中资源的状态。类型检查不修改运行时文件格式。

## 收藏、输入和预览状态

收藏类型保存在 `#favorites?type=component` 等 URL 中，支持 `component`、`block`、`page`、`case` 和 `motion`；全部类型省略该参数。分类和关键词叠加在收藏范围内，类型计数也以收藏为范围。导入继续使用版本 1 备份格式，严格验证完整资源键，整份验证和持久化成功后才更新当前状态。

列表搜索普通输入延迟 150ms，提交和非文本筛选立即执行；中文组合输入结束后才更新。导航会提交或取消待处理任务。快捷搜索的组合输入回车和方向键不会打开结果或移动焦点。

列表按资源键保留连接中的卡片，只新增或移除变化的结果；保留卡片的链接仍同步当前筛选条件。保持相对位置的 iframe 不会重新加载。必须移动节点时优先使用浏览器的 `moveBefore`，不支持该接口的浏览器退回普通移动，因此移动的 iframe 可能重载。离开可见区域的预览仍按预算回收。
